价值投资

巴菲特 · 查理·芒格
所有AI推荐散户最可行
市场短期非理性，长期有效。在股价低于内在价值时买入优质企业，长期持有。核心武器：耐心和对商业的理解。AI时代反而如虎添翼——AI能加速信息处理，但无法替代价值判断。
所需条件：能读财报 / 持有5年以上 / 接受中等波动
📌 真实案例2008年金融危机，可口可乐股价从高点跌近40%。巴菲特不但没卖，反而认为这是机会——因为可口可乐的品牌、定价权和全球渠道一分没变，只是股价暂时便宜了。危机后3年，股价涨回并创新高。这就是价值投资：判断企业价值，而不是判断股价走势。
🌱

成长股投资

菲利普·费雪 · 彼得·林奇
需要大量研究高波动
在市场发现之前识别高增长企业。通过深度研究（读年报、了解行业、接触上下游）找到增长性被低估的公司。AI实验中8个AI推荐的10年股票，覆盖TSMC、NVIDIA、CSU、LVMH等，每一只都是行业结构性成长的代表。
所需条件：每周5h+研究 / 10年以上视角 / 承受高波动
📌 真实案例2015年，英伟达（NVIDIA）还只是一家做游戏显卡的公司，市值不到100亿美元。少数人提前看到了AI算力的需求将爆发，买入并持有。10年后，NVIDIA市值突破3万亿美元，涨幅超过300倍。关键不是"NVIDIA今天值多少"，而是"5年后AI算力市场会有多大"——这是成长股投资的核心判断。
📊

指数/被动投资

约翰·博格（Vanguard创始人）
适合大多数人时间投入极少
买入市场整体，不择股不择时，持续定投让复利做功。AI实验中，在"每月定额投资20年"的问题上，7/8个AI选择了S&P500指数基金定投，核心理由：长期来看大多数主动基金无法稳定跑赢指数。
所需条件：高纪律 / 耐心 / 能"买了不看"
📌 真实案例如果你在2000年科技股泡沫顶峰买入S&P500指数基金，接下来经历了互联网崩盘（-49%）、2008年金融危机（-57%）两次大跌。但如果坚持每月定投不中断，到2020年的年化收益仍然超过7%，20年翻了近4倍。你不需要判断任何公司，只需要买"整个美国经济"，然后等待时间的力量。
📈

趋势投机

杰西·利弗莫尔 · 海龟交易员
高失败率需要强执行力
顺势操作，严格止损，让利润奔跑。不判断企业价值，只判断价格方向。真正的难点不是找到趋势，而是在止损被触发时没有任何犹豫地执行——统计数据显示，90%以上的趋势交易者长期亏损。
所需条件：铁一般的止损纪律 / 能接受频繁小损 / 快速执行
📌 真实案例2020年3月疫情冲击，A股开盘连续暴跌。趋势交易者不去判断"跌多少才是底"，而是看到下跌趋势已经形成，顺势做空或减仓，同时设好止损——一旦反转信号出现，立刻平仓甚至翻多。这套方法的难点不是判断方向，而是当止损价格被触发时，必须在5秒内执行，不管当时的情绪和理由。
🌐

宏观对冲

乔治·索罗斯 · 雷·达里奥
门槛极高普通散户慎入
利用宏观认知偏差和"反身性"循环做大方向押注。索罗斯本人说这套方法无法被系统性复制。AI实验中8个AI均未将宏观对冲推荐给普通投资者，但其思维框架对提升投资视角有价值。
所需条件：机构级工具 / 宏观判断力 / 大额资金
📌 真实案例1992年，索罗斯判断英镑被严重高估，而英国政府为了维持欧洲汇率机制不得不撑住汇率——这个矛盾迟早要爆。他借入大量英镑做空，英国央行拼命买入英镑来护盘，但最终资源耗尽，英镑单日暴跌15%，英国被迫退出汇率机制。索罗斯一天净赚10亿美元。这就是宏观对冲：押注政策现实和市场认知之间的矛盾。
